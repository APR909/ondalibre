    Acerca de OndaLibre

    OndaLibre es un reproductor de radio en directo de código abierto con identidad visual neón. Reúne 60 emisoras españolas nacionales, autonómicas y locales, y reproduce sus emisiones directamente en tu navegador: sin cuentas obligatorias, sin anuncios añadidos, sin servidor intermedio ni cookies propias.

    Cómo funciona

    La página es un directorio de enlaces. Cuando eliges una emisora, tu navegador se conecta directamente al servidor de emisión de esa emisora y reproduce el audio tal cual lo emite, incluida su publicidad. OndaLibre no recibe, almacena, graba, modifica ni redistribuye el sonido.

    Puedes marcar favoritas y añadir tus propias emisoras pegando la dirección de su emisión. Puedes buscar y combinar filtros de contenido, género y zona, o usar los accesos rápidos del catálogo para mostrar música, noticias o radios locales de Granada. La sección «Para ti» coloca tus favoritas y tus últimas escuchas sobre el catálogo, con accesos rápidos. Todo eso se guarda únicamente en tu navegador. También puedes iniciar sesión con Google opcionalmente para mostrar tu perfil en esta página y consultar tus radios y géneros más escuchados en este navegador. El acceso no sincroniza las favoritas ni las estadísticas entre dispositivos.

    Tecnología

    HTML, CSS y JavaScript
    Sin frameworks, sin compilación y sin dependencias de servidor. El código se entrega sin minificar para que pueda leerse y copiarse.
    Elemento <audio>
    Reproduce de forma nativa las emisiones MP3 y AAC (Icecast / SHOUTcast).
    hls.js 1.6.13
    Reproduce emisiones HLS (.m3u8) mediante Media Source Extensions en los navegadores que no las admiten de forma nativa. Es la biblioteca de reproducción externa, con licencia Apache-2.0, y se sirve desde esta misma página, no desde una CDN.
    Google Identity Services (opcional)
    Permite mostrar el perfil de Google en esta pestaña después de abrir el panel de acceso, si el propietario ha configurado un ID de cliente. No crea cuentas propias ni sincroniza datos.
    Logotipos de emisoras
    Se muestran imágenes de identificación enlazadas desde servidores externos, con carga diferida y un distintivo de texto cuando no hay imagen disponible. El navegador puede contactar con esos proveedores al mostrar las emisoras.
    Información «Ahora suena»
    La barra inferior muestra una descripción de la emisión. En 12 cadenas musicales puede consultar de forma opcional el índice público de Tuneping para obtener canción y artista, comprobando que la emisora coincida y que los datos sean recientes. Gozadera FM mantiene una fuente independiente de AzuraCast. Cuando faltan datos compatibles se muestra una descripción genérica, sin inventar títulos.
    Media Session API
    Conecta con las teclas multimedia y los controles de la pantalla de bloqueo. El indicador de barras de la parte inferior se anima cuando hay sonido en reproducción.
    localStorage
    Guarda en tu dispositivo el tema, el volumen, las favoritas, las emisoras añadidas, hasta ocho radios recientes, la última emisora y, si inicias sesión, las estadísticas locales de escucha.
    Propiedades personalizadas de CSS
    Tres temas (oscuro, claro y alto contraste) que por defecto siguen la preferencia del sistema. Tipografía del sistema: no se descargan fuentes.
    Alojamiento estático
    Son archivos estáticos: funcionan en GitHub Pages, en cualquier servidor web o abriendo index.html.
    Manifiesto de aplicación web
    Permite añadir la página a la pantalla de inicio del móvil y abrirla a pantalla completa, como una app.

    Privacidad

    • OndaLibre no establece cookies propias ni incorpora analítica remota o publicidad. Tus estadísticas personales de escucha solo se calculan en este dispositivo cuando inicias sesión. Los servidores de emisión se contactan cuando eliges una radio.
    • Los logos de las emisoras se cargan desde proveedores externos (por ejemplo, Facebook, X/Twitter o Wikimedia) al mostrarse en la lista o en el reproductor. Esos servicios pueden recibir tu dirección IP y datos técnicos de la conexión. Las imágenes se cargan sin enviar la URL de procedencia; puedes bloquearlas con ajustes del navegador.
    • Al escuchar emisoras musicales configuradas para «Ahora suena», la aplicación puede consultar el servicio público Tuneping, que indexa metadatos de emisiones, o el servidor AzuraCast de Gozadera FM. Los proveedores pueden recibir tu dirección IP y datos técnicos. Estas consultas solo se realizan con la emisión activa y la página visible, sin enviar credenciales, cuenta de Google, favoritas ni estadísticas. La información puede no estar disponible y no implica que el proveedor tenga una relación con OndaLibre.
    • Si abres el panel de acceso con Google y está configurado, se carga Google Identity Services desde los servidores de Google. Al iniciar sesión, Google devuelve datos básicos de tu cuenta (nombre y correo) para mostrarlos en la interfaz. OndaLibre no guarda el token ni tu perfil y no dispone de una base de datos de usuarios. Google puede tratar datos conforme a su propia política de privacidad. Privacidad de Google.
    • Tus preferencias, incluidas las emisoras favoritas y las escuchadas recientemente, se guardan solo en el almacenamiento local de tu navegador y no se envían a OndaLibre ni a Google. El historial reciente registra como máximo ocho emisoras y solo después de comenzar la reproducción; puedes borrarlo desde «Para ti» o desde los ajustes del navegador.
    • Si inicias sesión, se registra el tiempo de reproducción por emisora y género en el almacenamiento local de este navegador, separado por un identificador derivado de tu cuenta de Google. No se guarda tu correo, identificador original ni token de acceso junto a las estadísticas. No se comparten, no se sincronizan entre dispositivos y puedes borrarlas desde las pestañas «Mis radios» y «Mis géneros». Al cerrar sesión se ocultan, pero permanecen en este dispositivo hasta que las borres.
    • Al reproducir una emisora, tu navegador se conecta a los servidores de esa emisora o de su proveedor de emisión, que reciben tu dirección IP y los datos técnicos habituales de cualquier conexión web. Ese tratamiento corresponde a cada emisora y se rige por su propia política de privacidad.
    • Las emisiones de audio directo se reproducen mediante el reproductor nativo del navegador, sin exigir cabeceras CORS a los servidores de las radios. Esto evita fallos y reconexiones innecesarias, pero el proveedor de emisión recibe tu dirección IP y puede tratar datos técnicos de conexión. Las posibles cookies de terceros se rigen por las políticas y ajustes del navegador. OndaLibre no establece cookies propias ni transmite datos de Google o favoritos a las emisoras.
    • Las fuentes HLS procesadas mediante hls.js sí requieren que sus servidores permitan el acceso CORS a los fragmentos. La reconexión no puede eludir restricciones del navegador ni garantizar reproducción en segundo plano en Brave para Android.
    • El servidor que aloja esta página (por ejemplo, GitHub Pages) puede registrar tu dirección IP en sus registros técnicos, como cualquier sitio web.
